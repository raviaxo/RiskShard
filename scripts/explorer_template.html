Notice to readers — how to break a number
  1. Pick any figure in any item below.
  2. Follow it to the named source and the exact cited line — both are printed on the parameter's row.
  3. If the value, the source, or the caveat is wrong, use the [dispute] link on that row. It opens a pre-filled issue; state what is wrong and the public source that shows it.

Note 1 — Basis of preparation

Monte Carlo, 10,000 trials, seed 42, machine-independent seeding — a modeled range from public evidence, not a prediction. A parameter marked estimate is an interpretive value whose limitation is stated on its face; all other parameters cite a named public source. A parameter marked bridged is source-backed by evidence not drawn from this item's own cell — the dimension borrowed across (country, sector, size, threat) is named in its status. Bridging is declared, never hidden: a reader counting the source-backed total should not infer more cell-specific evidence than exists. Grades follow the maturity ladder: governed_starter → benchmark_review_candidate → benchmark-grade (the last only after a recorded human review; no item on this page holds it).
