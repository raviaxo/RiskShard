# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/raviaxo/RiskShard/security/advisories/new)
(Security → Report a vulnerability). We aim to acknowledge reports within a few
days.

RiskShard is a local, evidence-governed analysis tool with no network service and
no stored secrets, so the realistic surface is limited to the CLI/console and
dependency chain. Reports about dependency vulnerabilities, unsafe file handling,
or supply-chain concerns are all welcome.

## Supported versions

RiskShard is pre-1.0; security fixes land on `main`.
