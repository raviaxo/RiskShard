# Requested shards

What the community wants quantified next. This is RiskShard's demand signal: each row
is a country × sector × threat someone asked to see modeled. Repeated or strong
requests become the next objective in the internal queue.

## How to request one

Open an issue using the **"shard or source"** template and tag it `requested-shard`
(or just start a thread in **Discussions**). Describe the scenario and, if you have
them, the public sources that could back it. Want to build it yourself? See
[CONTRIBUTING.md](../CONTRIBUTING.md) and the end-to-end
[GOLDEN_CONTRIBUTOR_EXAMPLE.md](GOLDEN_CONTRIBUTOR_EXAMPLE.md).
